About GITT

GITT is a cloud technology platform designed to help users explore and understand different cloud computing platforms.

What is GITT?

GITT provides a simple interface for exploring major cloud platforms such as Amazon Web Services, Google Cloud Platform and Microsoft Azure.

Users can explore cloud services related to computing, storage, databases, networking and serverless computing.

Our Purpose

The purpose of GITT is to make cloud computing concepts easier to understand and provide users with a convenient way to explore cloud services.
